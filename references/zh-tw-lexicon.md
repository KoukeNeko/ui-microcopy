# 正體中文（台灣）UI 用語

The linter's `zh-tw-vocabulary` rule encodes the high-confidence half of this
list. The rest is for a person to decide.

## 詞彙

**必定改（mainland usage, wrong word in a Taiwanese interface）**

| 不用 | 用 |
| --- | --- |
| 當前 | 目前 |
| 默認 | 預設 |
| 軟件／硬件 | 軟體／硬體 |
| 硬盤 | 硬碟 |
| 內存 | 記憶體 |
| 字節 | 位元組 |
| 服務器 | 伺服器 |
| 緩存 | 快取 |
| 文件夾 | 資料夾 |
| 鼠標 | 滑鼠 |
| 屏幕 | 螢幕 |
| 視頻／音頻 | 影片／音訊 |
| 網絡 | 網路 |
| 消息 | 訊息 |
| 卸載 | 解除安裝 |
| 加載 | 載入 |
| 刷新 | 重新整理 |
| 菜單 | 選單 |
| 插件 | 外掛 |
| 移動端 | 行動裝置 |
| 賬號 | 帳號（「賬」是簡化字） |

**視情況改（acceptable in some Taiwanese writing, decide per screen）**

用戶→使用者、信息→訊息／資訊、數據→資料、保存→儲存、打印→列印、
點擊→點選／點一下、設置→設定、反饋→回饋、在線→線上、提交→送出、
文件→檔案、重啟→重新啟動、快捷鍵→快速鍵、剪貼板→剪貼簿、智能→智慧。

**留著不要改**：「品質」（不是「質量」）、「程式」（不是「程序」）、
「支援」（不是「支持」）、「設定」與「設置」在台灣的技術文件裡分工清楚，
一律用「設定」。

## 標點與排版

- 全形標點：，、。：；（）？！。中英夾雜時，標點跟著它所屬的語言。
- 省略號用「……」，不用「...」；範圍用連接號「–」（en dash），不用「~」。
- 按鈕、標籤、標題不加句號；句子型的 status 與 error 加句號。
- 中英之間、數字與單位之間留一個半角空格，同一專案內保持一致（例如
  「約 180 g（150–220 g）」）。
- 引號用「」與『』，不用 “ ”。
- 破折號用「——」，不用「-」或「--」。

## 既有慣例

- 按鈕：確定、取消、儲存、刪除、關閉、繼續、稍後、重新開機（不是「重啟」）。
- 狀態：已儲存、已同步、安裝完成、同步中、無法連線、沒有資料、尚未設定。
- 「請輸入…」是台灣標準的指示語氣，保留；「您的」「你的」只在需要區分
  資料歸屬時出現，「我們」不用。

## 一個必須靠人判斷的例子

`不計入` 本身不是贅語：MISHIRUBE 的「不計入連續達標」是一條真正的規則，
使用者判斷連續紀錄時需要它。linter 只在它跟餐具、容器、背景等**估算器材**
連用時才報錯（`apparatus-disclaimer`），因為那時候被說明的是量測的雜訊，
不是使用者要判斷的事實。詞彙規則如此，其餘規則也如此：規則抓的是模式，
最後一刀仍由人下。
